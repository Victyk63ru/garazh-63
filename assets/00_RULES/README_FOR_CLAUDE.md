# GARAZH — production assets v1

Статус: APPROVED PRODUCTION PACKAGE.

## Главное правило
Использовать графику из этой папки как готовые файлы. Ничего не перерисовывать, не генерировать и не заменять похожими библиотечными иконками.

## Логотип
`01_BRAND/logo-primary.png` — единственный допустимый логотип v1. Не набирать слово «ГАРАЖ» отдельным шрифтом. Не менять геометрию знака, надписей и пропорции.

## Роли
`02_ROLES/role-child.png`, `role-parent.png`, `role-master.png` — использовать для выбора роли и аватаров, где подходит.

## Система иконок
- CIRCLE_PERSONAL — личное/живое: профиль, достижения, события, помощь.
- HEX_SKILLS — навыки/мастерство: столярка, электрика, безопасность, инструменты.
- SQUARE_WORK — рабочие функции: проекты, задания, уроки, мой день.

## Картинки
- `sketch-birdhouse.png` — прозрачный карандашный скетч для карточек/главного проекта.
- `sketch-birdhouse-notebook.png` — полноформатный утверждённый сюжет для промо/портфолио.
- `photo-birdhouse.png` — фото проекта из утверждённого концепта.
- `photo-wood-crack.png` — фото для «Косяк → Урок».

## Запрет
Если в пакете нет нужной графики, Claude обязан сообщить, чего не хватает. Нельзя создавать замену самостоятельно.
